The **printed substrate** surface options each pair a real CC0 paper / board /
cloth relief (`card`, `board`, `kraft`, `hessian`, `linen` above) with the
hand-drawn terrain ink in `static/art`, for a printed-card / printed-board
finish.

The other three surface styles (`Procedural`, `Stylized`, `Material`) generate
everything at runtime and have no asset dependencies.
